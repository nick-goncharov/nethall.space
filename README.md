## 🎯 Краткое резюме проекта

### Что такое Nethall?
Платформа для проведения онлайн-мероприятий (мастер-классы, лекции, конференции) с:
- 🎥 Видеотрансляциями в реальном времени
- 💰 Встроенной системой оплаты и донатов
- 📅 Календарем и автоматическими напоминаниями
- 💬 Real-time чатом
- 👥 Управлением участниками
- 📊 Аналитикой и статистикой

### Целевая аудитория
- **Организаторы**: Коучи, преподаватели, эксперты
- **Участники**: Ученики, слушатели, зрители
- **Бизнес**: Университеты, школы, компании

---

## 🏗️ Рекомендуемый технологический стек

### Frontend
- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS + shadcn/ui
- **State**: Zustand + React Query
- **Video**: LiveKit Client SDK
- **Real-time**: Socket.io Client

### Backend
- **Runtime**: Node.js 20+ LTS
- **Framework**: Express.js / Fastify
- **Language**: TypeScript
- **Database**: PostgreSQL 16+
- **Cache**: Redis 7+
- **ORM**: Prisma
- **Video**: LiveKit Server SDK
- **Real-time**: Socket.io

### Infrastructure
- **Frontend Hosting**: Vercel
- **Backend Hosting**: DigitalOcean / AWS
- **Database**: Managed PostgreSQL
- **Storage**: S3 / DigitalOcean Spaces
- **CDN**: CloudFlare
- **Video Servers**: LiveKit (региональные)

### Integrations
- **Payments**: Stripe + CloudPayments
- **Email**: SendGrid / AWS SES
- **Push**: Firebase Cloud Messaging
- **Monitoring**: Sentry + Grafana
